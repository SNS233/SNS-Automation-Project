How Batch Correction Works

  • Upload your updated Excel or CSV file containing corrected village information.
  • Village Code is used as the primary matching key to locate existing records.
  • Existing villages will have their details (names, taluka, wells, GEB info) updated without creating duplicate records.
  • Surveyor assignments and completion statuses are strictly preserved.
  • Any new village codes present in the file will be added as new records for this batch.
